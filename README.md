# MindVector

Production landing page for [mindvector.tech](https://mindvector.tech), built with React, TypeScript, vinext, and modern CSS.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm test
```

The waitlist is intentionally frontend-only. No email is transmitted or stored.
